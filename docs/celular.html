Botón "Recolectar" para el celular

Se configura una sola vez. Después, cada día: abres tu panel de afiliados, tocas el marcador "Recolectar" y luego "Enviar al bot".

A. Actualiza el marcador (una vez)

  1. Toca "Copiar código nuevo".
  2. Abre los marcadores (ícono del libro), toca Editar y entra a Recolectar.
  3. Borra la dirección que tiene, pega el código y toca Listo.

B. Crea tu clave de GitHub (una vez)

Es lo que deja a tu celular enviar las ofertas a tu repositorio. Sirve solo para ese repositorio.

  1. Abre esta página de GitHub e inicia sesión.
  2. Token name: Bot ofertas celular.
  3. Expiration: elige la opción más larga que te ofrezca.
  4. Repository access: "Only select repositories" y elige bot-ofertas-ml.
  5. Permissions → Repository permissions → Contents: cámbialo a Read and write. No toques nada más.
  6. Toca Generate token y luego copia la clave (empieza con github_pat_). Solo se muestra una vez.

C. Cada día

  1. Abre tu panel de afiliados en este navegador.
  2. Abre los marcadores y toca Recolectar. Arriba aparece un aviso azul con el avance; tarda cerca de un minuto.
  3. Al terminar te lleva a "Enviar ofertas al bot". La primera vez te pide pegar la clave del paso B.
  4. Toca Enviar al bot. En unos 3 minutos están listas las imágenes, las páginas y los posts del día.
